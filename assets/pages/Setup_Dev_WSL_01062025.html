Setting up Development Environment in WSL

Complete guide to setting up a robust development environment using WSL, Docker, and Python tools for modern software development.

WSL Docker Python Development

We will be working inside WSL for our development environment. This setup provides a robust Linux environment on Windows with all the tools we need for modern development.

Getting Started with WSL

First, install WSL:

wsl --install

Install the Ubuntu distro:

wsl --install -d Ubuntu

Set the default version to WSL2:

wsl --set-default-version 2

Python Environment with pyenv

Install pyenv for Python version management:

curl -fsSL https://pyenv.run | bash

Note: Refer to the official pyenv documentation for detailed setup instructions.

For Zsh users, add these lines to your ~/.zshrc:

echo 'export PYENV_ROOT="$HOME/.pyenv"' >> ~/.zshrc
echo '[[ -d $PYENV_ROOT/bin ]] && export PATH="$PYENV_ROOT/bin:$PATH"' >> ~/.zshrc
echo 'eval "$(pyenv init - zsh)"' >> ~/.zshrc

Install a Python version:

pyenv install 3.10.5

Troubleshooting: If you encounter compilation errors, install the required build dependencies:

sudo apt install -y software-properties-common

Set a global Python version:

pyenv global 3.10.5

Package Management with pipenv

Install pipenv for virtual environment and dependency management:

python -m pip install pipenv

Initialize a new project:

pipenv install

Install packages in your virtual environment:

pipenv install tqdm

Conclusion

This setup provides a powerful, isolated development environment that combines the best of Windows and Linux. With WSL2, Docker, and proper Python tooling, you'll have everything needed for modern software development.
